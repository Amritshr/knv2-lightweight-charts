A financial charting engine written in C++, compiled to WebAssembly, drawn with WebGL2. No JavaScript runs on a frame.

Why it is different

Most web charts redraw from JavaScript. This one does not.

Nothing on the frame

The projection, hit-testing, text layout, input handling and render loop are all compiled C++ inside the engine. Panning uploads nothing and allocates nothing.

Built for long series

100,000 bars pan at frame rate. The chart above is holding 20,000 — drag it around and watch your CPU stay idle.

Drawing tools included

Trend line, ray, horizontal and vertical lines, extended, arrow, text and callout — hit-tested, selectable, draggable, with undo/redo. Not DOM overlays you have to build.

Any market, any feed

It takes an array. Stocks, futures, forex, crypto, or a CSV — if you can shape it into { time, open, high, low, close }, it charts. Nothing is fetched for you.

Live updates, in place

update() rewrites the forming bar without re-uploading the series. Point a WebSocket at it and leave it running.

Verifiable

Every shipped file has a published SHA-256, checked in the browser before the engine may run. No telemetry, no call-home, no network request but its own two files.

A complete chart, in six lines

No build step, no bundler, no account, no API key.

import { createChart } from './dist/knv2-lightweight-charts.js';

const chart = await createChart(document.getElementById('chart'), {
  type: 'candles',
  theme: 'dark',
});

chart.setData(bars);   // [{ time, open, high, low, close }]

Then chart.update(bar) on every tick. React, Vue, Svelte, Next.js and plain HTML are all covered in the docs.

Is it the right choice?

Written straight, because a bad fit helps nobody.

Use lightweight-charts instead if you need those 45 KB, an OSI-approved licence, readable source, or several series on one chart. It and this one is modelled on it.

What you get is the compiled engine, not the code. The download is a WebAssembly binary, its loader, a minified SDK and TypeScript definitions. The C++ source of the engine is not distributed and is not part of this package — see integrity & security for how to verify the binary you were given.
